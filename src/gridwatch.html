GridWatch

Real-time outage tracking platform designed to visualize power disruptions using user-reported data and live updates.

status: in progress

01 — Problem

In many regions, there is no reliable, real-time visibility into power outages. Users rely on guesswork, social media, or delayed updates from providers.

02 — System Flow

User reports outage → Location captured → Stored in database → Broadcast to map → Visible to other users

03 — Database Design

reports (id, user_id, location, status, timestamp) users (id, email)

Designed to capture user-reported outages as the primary signal, with flexibility to integrate external grid data later.

04 — Backend Logic

POST /api/outages/report
GET /api/outages
PATCH /api/outages/:id
GET /api/zones
(future) WebSocket → real-time updates

API structure is designed around real-time updates and aggregation, enabling efficient data flow between user reports and map visualization.

05 — Design Decisions

The system prioritizes user-reported data as the fastest signal for outages, ensuring immediate visibility even without official grid data.

An aggregation layer groups nearby reports to prevent duplication and maintain a clean, readable map interface.

A zone-based structure allows the system to scale from local neighborhoods to city-wide and eventually national grid visibility.

06 — Vision

The goal is to evolve into a real-time infrastructure layer for outage visibility, combining user reports with grid data to provide accurate, location-based insights.
