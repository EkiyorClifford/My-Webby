Problem

Founders often have a rough idea but no scoped MVP. Spark turns that ambiguity into a clear brief: problem, target user, prioritized features, suggested stack, a 2-week plan, and open questions.

What I built

  • Next.js App Router UI with streaming response panel
  • Server-side Groq Chat Completions (API key never exposed to the browser)
  • Round-2 founder Q&A that refines the MVP brief from answers
  • Stack preference, example chips, local history, copy/download, shareable links
  • Per-IP rate limiting to reduce abuse on a public demo

Why it matters

This is the same pattern used to ship AI features inside real products: product UX + Node API + LLM streaming — not a model-training research project.
