# Interview talking points

## 60-second pitch

I’m a full-stack product builder. I ship working systems — not just UI.

My strongest proof is **Serein**: a live spa booking product with Next.js, TypeScript, Supabase, and Paystack — customer booking, admin ops, payments, and availability.

For AI, I integrate LLM APIs into products. I built **Spark**, a live idea → MVP-spec tool with streaming OpenAI responses, rate limiting, and a Next.js API route. That’s the same pattern I’d use to turn your idea into a scoped MVP, then a clickable vertical slice in week one.

I’m available under 30 hrs/week, comfortable at $35/hr, and I’d start with a paid discovery milestone so we align on scope before building deep.

## “Tell me about your AI experience”

**Say this:**
- I build AI *features* into real apps: server-side API keys, streaming UX, prompts that produce structured product output, and basic abuse controls.
- Spark is the live demo — idea in, MVP brief out.
- Most “AI products” for founders are LLM APIs + solid product engineering, not training models from scratch. That’s where I work.

**Don’t say:**
- “I used ChatGPT/Cursor to help me code Serein” as your AI credential.

## Likely client questions → short answers

**What’s your process for a vague idea?**  
Clarify user + must-have outcome → cut MVP → ship one vertical slice → iterate with real feedback.

**Can you do Python / Java / AWS?**  
I’m strongest in JS/TS, React/Next, Node. For most MVP AI products that’s enough. If something truly needs Python services or AWS later, I’ll say so early and we can plan it — I won’t fake depth.

**When can you start?**  
Immediately for a discovery call; first milestone within the first week.

**How do you price?**  
$35/hr ongoing, or fixed milestone 1 (~$200) for discovery + PRD + architecture + week-1 plan.

## Questions to ask them

1. Who is the primary user and what job are they hiring the product to do?  
2. What must be true in 30 days for this to feel successful?  
3. Do you already have designs, a brand, or just the idea?  
4. Any compliance, payment, or data constraints?  
5. Preferred cadence for updates (async daily / 2x week calls)?

## Red flags — walk away if

- They ask to leave Upwork for payment before trust is established  
- Refuse any scope clarity but want a large retainer  
- Ask for free multi-day “trial” builds with no milestone
